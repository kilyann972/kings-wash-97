KING'S WASH 97 — MISE À JOUR SEO

1. Ouvrir le dépôt GitHub https://github.com/kilyann972/kings-wash-97
2. Cliquer sur Add file > Upload files.
3. Déposer index.html, sitemap.xml et robots.txt à la racine (pas le dossier).
4. Cliquer sur Commit changes.
5. Ne pas supprimer le dossier assets, CNAME ou og-kingswash97.png.
6. Vérifier https://kingswash97.fr/sitemap.xml
7. Dans Search Console > Sitemaps, soumettre https://kingswash97.fr/sitemap.xml

NOTE : index.html est une mise à jour SEO de la version de site déjà préparée, conservant les fonctions existantes.
